ZXC Random Crosshair 1.0
=======================
<img width="1213" height="793" alt="{8101C81A-E3B4-4ED8-93C7-0ED5F7F7D8CF}" src="https://github.com/user-attachments/assets/1d471248-c15a-467d-9529-838e0596f0aa" />

Случайный прицел для каждого танка в War Thunder.

УСТАНОВКА
---------
1. Распакуйте этот архив в любую папку, например C:\Games\ZXCRandomCrosshair.
2. Запустите ZXCRandomCrosshairGUI.exe.
3. Откройте «Настройки» и проверьте пути к global.blk и UserSights —
   обычно они определяются автоматически.

Установщик не нужен, программа переносится одной папкой.
Настройки сохраняются в %APPDATA%\ZXCRandomCrosshair\settings.json

ПЕРВЫЙ ЗАПУСК
-------------
Windows SmartScreen может показать предупреждение, потому что exe не подписан
сертификатом. Нажмите «Подробнее» -> «Выполнить всё равно».

ЧТО УМЕЕТ
---------
- назначает случайный прицел каждому танку после выхода из игры;
- скачивает прицелы с live.warthunder.com прямо из приложения;
- наборы прицелов: «Стандарт» и свои профили;
- автозапуск с Windows и работа в трее;
- автообновление с GitHub Releases (Настройки -> О программе);
- перед изменением global.blk создаёт резервную копию global.blk.zxc-backup.

УДАЛЕНИЕ
--------
1. Выключите «Запускать вместе с Windows» в настройках программы.
2. Выйдите из программы через меню в трее.
3. Удалите папку с программой.
4. При желании удалите %APPDATA%\ZXCRandomCrosshair.
